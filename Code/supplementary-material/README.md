# Curiosity by Design: An LLM-based Coding Assistant Asking Clarification Questions

## Datasets

### `clarification_module_synth_dataset.json`

A synthetic dataset consisting of vague or incomplete user programming prompts paired with model-generated clarification questions. Used to train the Clarification Module on generating useful follow-up questions in response to under-specified queries.

### `classifier_train_dataset.json`

A synthetic labeled dataset of user prompts with accompanying metadata indicating the level of ambiguity or need for clarification (on a graded scale from 1 to 4). Intended for training the Intent Classifier to detect whether a prompt requires a clarification question.

### `test_pipeline.csv`

A CSV file used for testing the end-to-end pipeline consisting of the Intent Classifier, Clarification Module and the baseline Gemma-3-1b-it model to finally generate answers. Includes columns for input prompts, generated clarification questions (by the Gemma-3-1b-it model), and the follow up by the user to answer the clarification question.

### `Sample of User Study RQ1_ _name of user_.pdf`

A sample document for the user study for Research Question 1 (RQ1), focused on evaluating the quality of clarification questions based on criteria such as 'Precision and Focus', 'Immediate Editability', and 'Contextual Fit'. Annotators provide preference ratings between two clarification questions generated by the Clarification Module and baseline Gemma-3-1b-it model.

### `Sample of User Study RQ2_ _name of user_.pdf`

A sample document for the user study for Research Question 2 (RQ2), centered on assessing the quality of full responses generated by the full pipeline. Annotators grade responses given by the pipeline against directly using the baseline Gemma-3-1b-it model. Includes evaluation metrics like 'Precision and Focus', 'Contextual Fit', 'Answer Faithfulness' and 'Correctness'.

## Training Scripts

### `intent_classifier.py`

Training script for the Intent Classifier Module, responsible for grading ambiguity of user prompts on a scale of 1 to 4.

### `clarification_module.py`

Training script for the Clarification Module, responsible for asking clarification questions to user prompts flagged as ambigious or under-specified by the Intent Classifier Module.

## Testing Scripts

### `test_classifier.py`

Testing script for the Intent Classifier Module on data it has not encountered in the training phase.

### `test_clarification_module.py`

Testing script for the Clarification Module on data it has not encountered in the training phase.

### `test_pipeline.py`

Testing script for the entire pipeline, specifically including the Clarification Module. This script has prompts from the `test_pipeline.csv` file. It feeds the initial user prompt, a clarification question, and a follow-up answer (as if provided by the user) into the Gemma-3-1b-it baseline model, which then generates a response to the original prompt enriched with the additional context gained through clarification.

## User Study Results

### `Stat tests_ RQs - RQ1.csv`

Contains results of the user study done for RQ1, noting scores for 'Precision and Focus', 'Immediate Editability' and 'Contextual Fit' with Mean, Standard Deviation, % times the Clarification Module's responses were preferred over the baseline Gemma-3-1b-it model and % times the Clarification Module's responses were as good as the baseline Gemma-3-1b-it model.

### `Stat tests_ RQs - RQ2.csv`

Contains results of the user study done for RQ2, noting scores for 'Precision and Focus', 'Contextual Fit', 'Answer Faithfulness' and 'Correctness' with Mean, Standard Deviation, % times the responses generated by our pipeline were preferred over directly using the baseline Gemma-3-1b-it model and % times the responses generated by our pipeline were as good as directly using the baseline Gemma-3-1b-it model.
