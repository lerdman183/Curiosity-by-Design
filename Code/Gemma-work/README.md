# Gemma-work
A folder containing scripts and old content from previous work on this project with Gemma-3-1b-it and DistilBERT


## Datasets/results
Old datasets and results can be found in `Datasets/unused-old-data`


### 2025 User Study
The `User-Study/` folder contains the materials used for the two research questions:

- **RQ1** — Are the clarification questions themselves useful? Annotators rate clarification questions from the Clarification Module against those from baseline Gemma-3-1b-it on Precision and Focus, Immediate Editability, and Contextual Fit.
- **RQ2** — Does the full pipeline produce better final answers? Annotators rate full pipeline responses against the baseline on Precision and Focus, Contextual Fit, Answer Faithfulness, and Correctness.

Sample annotation documents and anonymized participant responses are included.


## 2025 User Study Results

### `Stat tests_ RQs - RQ1.csv`

Contains results of the user study done for RQ1, noting scores for 'Precision and Focus', 'Immediate Editability' and 'Contextual Fit' with Mean, Standard Deviation, % times the Clarification Module's responses were preferred over the baseline Gemma-3-1b-it model and % times the Clarification Module's responses were as good as the baseline Gemma-3-1b-it model.

### `Stat tests_ RQs - RQ2.csv`

Contains results of the user study done for RQ2, noting scores for 'Precision and Focus', 'Contextual Fit', 'Answer Faithfulness' and 'Correctness' with Mean, Standard Deviation, % times the responses generated by our pipeline were preferred over directly using the baseline Gemma-3-1b-it model and % times the responses generated by our pipeline were as good as directly using the baseline Gemma-3-1b-it model.

## Old Training Scripts

### `test_pipeline.py`

Testing script for the entire pipeline, specifically including the Clarification Module. This script has prompts from the `test_pipeline.csv` file. It feeds the initial user prompt, a clarification question, and a follow-up answer (as if provided by the user) into the Gemma-3-1b-it baseline model, which then generates a response to the original prompt enriched with the additional context gained through clarification.
